# Hidden Number Discovery System

A modern and responsive web application designed to help users identify unknown phone numbers, detect spam callers, manage contacts, and track search history. The system provides a user-friendly dashboard with search, reporting, analytics, and profile management features.

## Features

### Authentication

* User Login
* User Registration
* Forgot Password
* Reset Password
* Remember Me Functionality

### Dashboard

* Statistics Overview
* Search Activity Summary
* Recent Searches
* User Activity Tracking
* Analytics Charts

### Number Search

* Search Unknown Numbers
* Country Code Selection
* Search Suggestions
* Recent Searches
* Search Result Details
* Number Status Indicators

### Search Results

* Number Information
* Network Provider
* Location Information
* Risk Level Assessment
* Report Statistics
* Last Updated Information

### Contact Management

* Save Contacts
* Edit Contacts
* Delete Contacts
* Search Contacts
* Export Contact Lists

### Search History

* View Search Records
* Filter Search History
* Delete History Records
* Export Search Data

### Number Reporting

* Report Spam Numbers
* Report Scam Calls
* Upload Supporting Evidence
* Track Report Status

### Notifications

* System Notifications
* Search Alerts
* Report Updates
* Mark as Read
* Delete Notifications

### User Profile

* Profile Management
* Update Personal Information
* Change Password
* Account Settings

### Settings

* Theme Selection
* Language Preferences
* Privacy Settings

### Admin Panel

* User Management
* Search Monitoring
* Report Management
* Analytics Dashboard
* System Statistics
